# ghostnode

Built by DARKSOL 🌑

`ghostnode` は Node.js アプリ向けのプライバシー・ファイアウォールです。

外向きの境界を監視し、機密データがプロセスの外へ出ようとした時に検知します。

## 現在の機能

- `fetch`
- `console`
- 汎用 logger
- `createPinoLogger(...)`
- `createWinstonLogger(...)`
- `ghostnode scan` の JSON レポート出力
